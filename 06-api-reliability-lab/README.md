# 06 API Reliability Lab

500, 429, timeout 실패를 재현하고 재시도 정책, 지수 백오프, 구조화 로그, 멱등 키를 최소 구현으로 검증한다.

## MVP

- 실패하는 외부 API 시뮬레이터
- timeout, 500, 429 처리
- 지수 백오프와 최대 재시도
- JSON 구조화 로그
- 동일 멱등 키의 중복 실행 방지

## Not Doing

대규모 모니터링 스택, 전체 분산 추적

## Done

- [x] 500/429에 재시도와 backoff를 적용한다.
- [x] timeout은 정해진 횟수 뒤 중단한다.
- [x] 멱등 키가 같은 요청은 한 번만 실행한다.
